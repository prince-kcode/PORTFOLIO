## 🚀 Run Locally

### Prerequisites
- **Node.js ≥ 18** — [Download Node.js](https://nodejs.org/)

### 1. Clone repository
```bash
git clone https://github.com/prince-kcode/PORTFOLIO.git
cd PORTFOLIO
```

### 2. Install dependencies & start dev server
```bash
npm install
npm run dev
```

The application will start locally at `http://localhost:3000/PORTFOLIO/`.
